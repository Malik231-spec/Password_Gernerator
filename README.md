🔐 Strong Password Generator

A simple yet powerful Password Generator built completely with Python.
Generate secure and random passwords using letters, digits, and symbols according to your desired password length.

✨ Features

✅ Strong Random Password Generation
✅ User-Defined Password Length
✅ Includes:

Uppercase Letters
Lowercase Letters
Digits
Special Symbols

✅ Infinite Loop Support
✅ Easy-to-Use CLI Interface
✅ Quit Anytime Using Q or q
✅ Beginner Friendly Python Project
✅ Lightweight & Fast

🧠 How It Works
The program asks the user to:
Enter password length
OR press Q to quit
If a number is entered:
A strong random password is generated

If the user enters:

q

or

Q

the program exits with:

Thanks for using me.
🔒 Password Contains

Generated passwords may include:

Type	Examples
Uppercase Letters	A-Z
Lowercase Letters	a-z
Digits	0-9
Symbols	!@#$%^&*
🚀 Example Output
Create Strong Passwords According to Your Need
